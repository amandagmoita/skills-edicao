# Skills de edição de Reels

Pacote com 14 skills, scripts, referências, fontes e recursos visuais. Conteúdo original em `skills/`, padrões compartilhados em `padroes-edicao/` e instruções em [LEIA-ME.md](LEIA-ME.md).

## Uso na nuvem

Clone este repositório no ambiente de trabalho para acessar os arquivos. O envio ao GitHub não instala automaticamente os skills no assistente.

O pacote original foi desenvolvido para Claude Code e macOS. Scripts Swift que usam Apple Vision, AppKit e recursos do sistema não funcionam diretamente em Linux; precisam de alternativas para recorte, medição e ícones. Transcrição e geração de imagens podem exigir serviços externos e chaves configuradas no ambiente. Nunca coloque chaves no repositório.

O instalador original `instalar.sh` é voltado ao Mac. Consulte o código e as dependências antes de executá-lo em outro ambiente.
